# Developer documentation

The introductory slide deck is built from the Python script in this folder.

```powershell
python -m pip install -r devdocs\requirements.txt
python devdocs\generate_crop_protection_intro.py
```

Output:

- `CropProtection_Introduction.pptx`

The deck introduces the component's purpose, model inputs, parameter hierarchy,
runtime behaviour, demo repository layout, product/active-substance handling,
outputs, and browser UI workflow.
